# C Projects Showcase



Репозиторий содержит коллекцию учебных и прикладных проектов, написанных на языке **C** (и **C++** с использованием SDL2). Проекты демонстрируют применение базовых алгоритмов, работу со структурами данных, управление памятью, а также создание консольных приложений и графических интерфейсов (GUI).



---



## 🛠 Технологии и библиотеки



* **Языки:** C, C++

* **Компиляция:** GCC / MinGW, MSYS2

* **Графические библиотеки и API:** WinAPI, Raylib, SDL2

* **Структуры данных:** Динамические массивы, стеки, кастомные структуры данных



---



## 📂 Обзор проектов



### 1. 🧮 Калькулятор математических выражений (Console & WinAPI)

Реализация калькулятора, использующая **алгоритм сортировочной станции (Shunting-yard algorithm)** для перевода математических выражений из инфиксной записи в обратную польскую нотацию (RPN) и их последующего вычисления через стек. Поддерживает приоритеты операций, круглые скобки и обработку унарного минуса.



* **`calculator_console.c`** — Консольная версия калькулятора с поддержкой истории вычислений.

* **`calculator_gui.c`** — Версия с графическим интерфейсом, написанная с использованием чистого **WinAPI** (`windows.h`).



### 2. 🐍 Игра «Змейка» (`snake.c`)

Классическая игра «Змейка», разработанная с использованием графической библиотеки **Raylib**.

* Реализована сетка игрового поля, генерация яблок с проверкой коллизий и обработка ввода с клавиатуры.

* Отрисовка элементов выполнена с кастомными деталями (глаза у змейки, скругление сегментов).



### 3. 📦 Система управления складом (`manager.c`)

Модульное консольное приложение для учёта и управления товарами на складе.

* **Особенности:** Динамическое выделение и масштабирование памяти (`malloc`/`realloc`), сохранение и загрузка данных из бинарных файлов (`data.dat`), проведение операций продажи, удаления и формирования отчётов.

* **Архитектура:** Разделение кода на заголовочные и исходные файлы (`product.h`, `storage.h`, `report.h`, `io_utils.h`).



### 4. ❌⭕ Игра «Крестики-Нолики» (`tic-tac-toe.cpp`)

Двухпользовательские «Крестики-нолики» с графическим интерфейсом на базе **SDL2**.

* **Особенности:** Кастомный алгоритм отрисовки цифр счета через 7-сегментный индикатор, определение победных линий и ничьих, обработка кликов мыши и автоматический сброс поля.
